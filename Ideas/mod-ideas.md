# Mod ideas to talk about

Picked from requests on the Steam forum (https://steamcommunity.com/app/1877960/discussions/0/), 2026-11-25.
Nothing here is built yet.

## Picked

- **Sounds and alerts.** A sound (and maybe a desktop notification) for things like a void map or map run
  finishing, a Zone being reached, or the army dying, for players who leave the game in the background.
  https://steamcommunity.com/app/1877960/discussions/0/761797931977198986/
- **Edit perk presets without loading them.** Loading a preset needs a respec, so presets can't be adjusted
  before a new run. Would fit in Perkalator.
  https://steamcommunity.com/app/1877960/discussions/0/6296618058087875914/
- **List of bought upgrades.** Upgrades bought this run with their descriptions, for when one is clicked before
  it was read.
  https://steamcommunity.com/app/1877960/discussions/0/603037248743555581/

## Undecided

- **Prestige count on every map button.** The game already shows "Items: N" for the selected map and in the
  map tooltip; this would show it on each map in the list. Undecided because it gets messy once you can run
  maps above your current Zone (the count depends on the map level).
  https://steamcommunity.com/app/1877960/discussions/0/744882977527392665/

## Skipped

- Remember the buy amount (+1/+10/Max) across loads: not relevant.
- Warpstation count in the Gigastation tooltip: unnecessary.
- Tooltips that avoid the health bars: non-issue, formations have hotkeys.
